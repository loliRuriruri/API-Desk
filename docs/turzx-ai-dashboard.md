# TURZX 3.5" AI 텔레메트리 대시보드

API Desk가 수집하는 GPU·로컬 AI 서비스·계정 쿼터·API 사용량을
TURZX/UsbMonitor 계열 3.5" USB 디스플레이(Rev A)에 표시한다.

## 하드웨어

| 항목 | 값 |
| --- | --- |
| 모델 | TURZX/UsbMonitor 3.5" (USB35INCHIPSV2) |
| USB | VID `1A86` / PID `5722` (CDC-ACM) |
| 해상도 | 320x480 (세로) / 480x320 (가로) |
| 통신 | 115200bps, RTS/CTS 하드웨어 흐름 제어 필수 |
| 확인된 서브모델 | 정식 Turing 3.5(HELLO 무응답), UsbMonitor 3.5/5/7(`[1..3]×6` 응답) |

## 프로토콜 요약(독립 재작성)

공개된 Rev A 프로토콜 사실만 사용해 C/Rust로 재구현했다. 참조 구현
(mathoudebine/turing-smart-screen-python 등)의 코드는 복사하지 않았으며,
해당 프로젝트들은 GPL-3.0으로 배포된다.

- 명령 패킷: 6바이트 = 10비트 `x/y/ex/ey`(양끝 포함 사각형) + 명령 바이트
  - `HELLO=69(0x45)`, `RESET=101`, `CLEAR=102`, `TO_BLACK=103`,
    `SCREEN_OFF=108`, `SCREEN_ON=109`, `SET_BRIGHTNESS=110`,
    `SET_ORIENTATION=121`, `DISPLAY_BITMAP=197`
- HELLO: `0x45` 6바이트 → 6바이트 응답. **정식 Turing 3.5는 응답하지 않으며
  이 경우도 정상**으로 보고 320x480으로 진행한다.
- `SET_ORIENTATION`: 6바이트 패킷 + `[방향+100, 폭(BE16), 높이(BE16)]` = 11바이트
  - 방향: 0=세로, 1=180° 세로, 2=가로, 3=180° 가로(하드웨어 처리)
- 픽셀: RGB565 little-endian, 청크 = 화면 폭 × 8 (2560/3840바이트), 청크마다 flush
- 밝기: 장치 값 0=최대, 255=최소 → 퍼센트를 반전해 전송
- 전송 중 변경: 밝기/방향은 재연결 없이 즉시 재적용, 그 외 설정은 다음 프레임부터 반영

## 아키텍처

```
src-tauri/src/turzx/
├── mod.rs      # 설정 파일·상태·워커 루프·Tauri 커맨드
├── protocol.rs # Rev A 패킷/RGB565/더티 렉트/PNG 쓰기(무의존)
├── device.rs   # COM 후보 점수화(VID/PID/시리얼) + 자동 선택
├── gdi.rs      # 무의존 GDI 캔버스(텍스트/바/원)
└── renderer.rs # 대시보드 레이아웃(단일/런타임/API) + 샘플 스냅샷
```

- 기존 GPU 모니터 캐시(`gpu_monitor::cached_snapshot`)와 모니터 스냅샷을
  재사용한다. **표시 탱크는 provider API를 호출하거나 새로운 폴링을 만들지 않는다.**
- 표시 데이터에 시크릿·명령줄·환경변수를 포함하지 않는다. Vault를 읽지 않는다.
- 출력 전용: 디스플레이는 서비스를 시작/중지하지 않는다.
- 연결이 끊기면 1s → 2s → 5s → 10s 백오프로 자동 재연결하고, 재연결 후
  전체 프레임을 다시 보낸다.

## 설정

`설정 → TURZX 3.5" 디스플레이` 섹션에서 다음을 설정한다.

- 디스플레이 사용 / 앱 시작 시 자동 연결 / 연결이 끊기면 자동 재연결
- COM 포트(자동 = TURZX 우선, 후보 목록에서 수동 선택)
- 화면 방향(세로/가로)·회전(0/90/180/270)·밝기(10–100%)
- 갱신 주기(1–30초), 표시 페이지(단일/런타임/API/자동 로테이션), 로테이션 주기(5–60초)
- 기기 이름(대시보드 헤더 문구)
- 미리보기(샘플/실시간 + 페이지 전환)와 PNG 내보내기

설정은 `%APPDATA%\com.apidesk.desktop\turzx-display.json`에 저장된다(외부 편집 시 UTF-8 BOM 없이).

## 대시보드 페이지

- **단일**: GPU 요약 + GPU 모델 목록(관리 서비스 > VRAM > 기타) + API 사용량 요약
- **런타임**: GPU/VRAM·프로세스 상세
- **API**: 계정별 남은 사용량(남은 % 기준 정렬, 최대 4행)

## 문제 해결

- `후보 포트를 찾을 수 없습니다`: USB 케이블/드라이버 확인. 후보가 여러 개면 설정에서 수동 선택.
- `열기 실패(액세스 거부)`: 다른 앱(제조사 유틸 등)이 COM 포트를 점유 중 → 종료 후 재시도.
- 5"/7" UsbMonitor 응답이 감지되면 "지원하지 않는 패널" 오류를 표시한다(320x480 레이아웃만 지원).
- 패널이 HELLO에 응답하지 않아도 정상이다(정식 Turing 3.5 동작).
- 연결 해제 상태에서도 앱·미니 창은 정상 동작한다.
