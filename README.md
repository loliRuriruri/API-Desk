# API Desk

> 이 문서는 로컬 우선(local-first) API 관리 데스크톱 앱 **API Desk**를 설명하는 문서다.
> 위키 문법이 아니라 GitHub 문서 문법으로 작성했지만, 서술 방식은 위키 스타일을 따랐다.

---

## 1. 개요

**API Desk**는 API 키와 계정 쿼터·사용량을 한곳에서 관리하는 **Windows 데스크톱 앱**이다.
흩어져 있는 API 키를 안전하게 모아 두고, 각 서비스의 잔여 사용량을 한 화면에서 확인하는 것을 목적으로 한다.

- **개발**: Tauri 2 (Rust) + React 19 + TypeScript + Vite
- **저장**: 메타데이터는 SQLite, 비밀 값은 IOTA Stronghold 볼트(암호화)
- **배포 형태**: MSI / NSIS 설치 프로그램, 트레이 상주형
- **UI 언어**: 한국어

한 줄로 요약하면 **"API 키 금고 + 사용량 관제판"** 인 셈이다.

## 2. 특징

| 항목 | 설명 |
| --- | --- |
| 로컬 우선 | 모든 데이터는 사용자 PC에만 저장된다. 별도 서버로 전송하지 않는다. |
| 키 암호화 | API 키는 Stronghold 볼트에 암호화되어 저장되고, 화면에는 요청할 때만 표시된다. |
| 사용량 모니터링 | 구독형 서비스는 물론 API 키 기반 서비스까지 남은 한도를 수치·게이지로 보여준다. |
| 트레이 상주 | 창을 닫아도 트레이에 남고, PC 시작 시 창 없이 조용히 실행할 수 있다. |
| 미니 창 | 항상 위에 떠 있는 소형 창으로 사용량만 빠르게 확인할 수 있다. |
| 임계치 알림 | 잔여 사용량이 설정한 비율 이하로 떨어지면 Windows 알림을 보낸다. |
| 테마 | 다크 / 라이트 / 아쿠아 글로스(프루티거 에어로) 테마를 제공한다. |

### 2.1. 보안 관련 서술
- 마스터 비밀번호는 **4자 이상**을 요구한다. (짧은 비밀번호를 허용하는 대신, 실사용 편의를 우선한 설계다.)
- 비밀 값 복사 시 지정 시간이 지나면 클립보드에서 자동으로 지운다.
- 일정 시간 입력이 없으면 볼트가 자동으로 잠긴다.
- 볼트가 잠긴 상태에서도 **계정 쿼터 모니터링은 계속 동작**한다. 키가 필요한 API 사용량 조회만 잠금 해제 후 가능하다.

## 3. 모니터링 대상

API Desk는 서로 다른 두 종류의 사용량을 추적한다.

### 3.1. 계정 쿼터 모니터 (구독 계정)

| 모니터 | 데이터 출처 | 비고 |
| --- | --- | --- |
| Codex | ChatGPT 계정 인증 파일 + 사용량 API | 주간/5시간 창, 리셋 시각 표시 |
| Grok Bot | xAI 청구 API + 구독 정보 | 월 한도가 제공되지 않으면 **월 목표** 대비 게이지로 표시 |
| Grok Build | grok CLI 빌링 조회 | CLI 미설치·미로그인 시 사유 표시 |
| Antigravity | 로컬 RPC(사용자 상태·쿼터) | **계정 탭**으로 여러 계정의 잔여량 확인 |
| OpenCode Go | Go usage API | 롤링/주간/월간 %, 로컬 세션 집계 폴백 |

### 3.2. API 사용량 어댑터 (키 기반)

| 어댑터 | 조회 내용 |
| --- | --- |
| OpenRouter | 크레딧 잔액 + 키 한도 (두 게이지로 분리 표시) |
| DeepSeek | 잔액 |
| Tavily | 사용/한도/남음 |
| OpenAI | 조직 비용(Admin 키) |
| Anthropic | 조직 비용 리포트(Admin 키) |
| xAI | 선불 잔액(Management 키 + Team ID) |

## 5. 설치

1. `API Desk_0.1.0_x64-setup.exe`(또는 MSI)를 실행한다.
2. 설치 마법사는 한국어로 진행되며, 환영 화면에 간단한 소개가 표시된다.
3. 설치 완료 후 실행하면 볼트를 만들기 위한 마스터 비밀번호를 설정한다.

### 5.1. 데이터 저장 위치
설치 폴더가 아닌 **사용자 데이터 폴더**에 저장되므로, 재설치해도 데이터는 유지된다.

| 종류 | 경로 |
| --- | --- |
| 메타데이터 DB | `%APPDATA%\com.apidesk.desktop\apidb.db` |
| 볼트(키) | `%LOCALAPPDATA%\com.apidesk.desktop\vault.hold` |
| 볼트 솔트 | `%LOCALAPPDATA%\com.apidesk.desktop\vault.salt` |
| Antigravity 계정 | `%APPDATA%\com.apidesk.desktop\antigravity-accounts\` |

> **주의**: 재설치는 앱 파일만 교체한다. 제거 프로그램으로 삭제해도 위 데이터는 남는다. 완전 삭제는 수동으로 해야 한다.

## 6. 트레이와 자동 시작

- 트레이 아이콘 **왼쪽 클릭** → 미니 창
- 트레이 아이콘 **오른쪽 클릭** → 열기 / 미니 창 / 사용량 새로고침 / 종료
- 설정에서 `Windows 시작 시 자동 실행`을 켜면 부팅 시 **창 없이 트레이에서만** 실행된다.

## 8. 개발과 빌드

```bash
npm install
npm run dev            # 프런트엔드 개발 서버
npm run tauri dev      # 데스크톱 개발 실행
npm run lint           # ESLint
npm run typecheck      # tsc --noEmit
npm test               # Vitest

npm run tauri build    # 릴리스 빌드 (MSI + NSIS)
```

- Rust 테스트: `cd src-tauri && cargo test`
- 직접 만든 실행 파일만 단독 실행하면 개발 서버(`localhost:1420`)를 바라보므로 화면이 비어 보일 수 있다. 반드시 `npm run tauri build` 산출물을 사용한다.

## 9. 알려진 제한

- **Windows 전용**이다. (Tauri 특성상 이식은 가능하지만 현재 배포 대상은 Windows뿐이다.)
- Antigravity 모니터는 로컬 실행 중인 앱의 RPC에 의존하므로, Antigravity가 꺼져 있으면 조회할 수 없다.
- Antigravity 다중 계정은 **현재 로그인된 계정의 쿼터만 실시간**으로 얻을 수 있다. 다른 계정은 마지막 확인 값으로 표시되고, 전환 후 갱신해야 한다.
- Grok Bot은 서비스가 월 한도를 제공하지 않아 **사용자가 정한 월 목표** 대비 게이지로 보여준다.
- Codex의 5시간 창은 서버가 제공하지 않으면 항목 자체가 표시되지 않는다.

## 10. 문제 해결

| 증상 | 원인과 대처 |
| --- | --- |
| 설치 후에도 이전 화면이 보인다 | 실행 중인 앱이 파일을 잠근 경우다. **트레이 → 종료** 후 다시 설치한다. |
| 미니 창이 하얗게 나온다 | WebView2 데이터가 손상된 경우다. 앱과 WebView2 프로세스를 종료한 뒤 `scripts/fix-webview.ps1`로 복구한다. |
| API 사용량 새로고침(↻)이 안 눌린다 | 볼트가 잠긴 상태다. 메인 창에서 잠금을 해제하면 활성화된다. |
| Antigravity 조회가 실패한다 | Antigravity가 실행 중인지 확인한다. 실행 중이면 로그에 남지 않은 새 포트/토큰을 자동으로 찾아 재시도한다. 그래도 실패하면 Antigravity를 재시작한 뒤 ↻를 누른다. |
| 키를 바꿨는데 값이 그대로다 | 잠금 해제 후 ↻를 누르거나, 6시간 이상 지난 스냅샷은 잠금 해제 시 자동 갱신된다. |
| 항목이 남았는데 순서가 이상하다 | 미니 창은 *계정 쿼터 → 모델 → API 사용량* 순으로 고정되어 있다. |

## 11. 여담

- 미니 창은 잠금 상태에서 무엇을 볼 수 있는지가 설계의 출발점이었다. 그래서 잠금 중에는 새로고침 버튼이 자물쇠로 바뀌고, 조회 시각이 "방금 전 / N시간 전" 형태의 작은 표식으로 표시된다.
- 테마 중 **프루티거 에어로 아쿠아 글로스**는 물방울 유리 질감을 재현한 것으로, 반투명 패널과 광택 버튼이 특징이다.
- 설치 마법사 역시 한국어로 번역되어 있고, 사이드바에 앱 아이콘이 들어간다.
- 사용량 게이지는 "남은 비율"을 기준으로 색이 바뀐다. 60% 이상 초록, 30% 이상 노랑, 그 아래는 빨강이다.
