# 한강데이 플래너 Android

2026-10-09 가족 나들이용 개인 APK.

## 기능
- 11시 사당 염소탕 이후 A/B 자동 판정
- 한강버스 운항상태/잔여좌석/번호표 입력
- 카카오 Local API + Kakao Mobility Directions API로 현재 교통 기준 이동시간/거리/예상 택시비 조회
- 카카오T 앱 실행 (예약 최종 확정은 카카오T 앱에서 처리)
- 서울달 네이버 예약 바로가기
- 63 SkyPicnic / 렛츠런파크 바로가기
- 10/9 11:20 로컬 알림

## API 키
앱의 설정에서 Kakao Developers REST API 키를 입력합니다. 키는 APK에 포함되지 않고 Android SharedPreferences에 로컬 저장됩니다.

## 주의
한강버스 실시간 잔여좌석은 서울시가 네이버지도/카카오맵에 제공하지만 외부 앱용 공개 좌석 API가 확인되지 않아 지도 확인 후 숫자를 입력하는 방식입니다.
